# Provision API and MCP server for Claude and ChatGPT

Provision publishes no public API or MCP server. Cotlet connects ChatGPT, Claude and other AI agents to your Provision account with hosted tools for project documents, scope gaps, scope packages, contract risks and review checklists.

## What you can ask

> Ask questions across your Provision project documents.

> Identify missing, unclear or conflicting scope before bid day.

> Generate a standardized scope package for a trade.

> Flag risky clauses and commercial exposures in contract documents.

> Create or update a review checklist for your team.

## Connect in 2 minutes

Get your API key at https://cotlet.dev/app and export it as `COTLET_API_KEY`.

### Claude Code

```bash
claude mcp add --transport http cotlet https://cotlet.dev/mcp/v1 --header "Authorization: Bearer $COTLET_API_KEY"
```

### ChatGPT

Settings → Apps → add connector URL `https://cotlet.dev/mcp/v1`, then sign in with Cotlet.dev. No API key needed.

### Cursor

Copy `.cursor/mcp.json` from this repo into your project:

```json
{
  "mcpServers": {
    "cotlet": {
      "url": "https://cotlet.dev/mcp/v1",
      "headers": {
        "Authorization": "Bearer ${COTLET_API_KEY}"
      }
    }
  }
}
```

## Run it locally (stdio)

This repo is a real MCP server. It speaks MCP over stdio, lists its Provision tools without any key, and forwards every tool call to the hosted Cotlet.dev server. The hosted URL above stays the recommended way. Use this when your client only starts local servers.

```json
{"mcpServers":{"provision":{"command":"uvx","args":["provision-mcp"],"env":{"COTLET_API_KEY":"your-key"}}}}
```

Or with Docker:

```bash
docker build -t provision-mcp .
docker run -i --rm -e COTLET_API_KEY provision-mcp
```

Tools: `provision_guide`, `provision_status`, `provision_open`, `provision_read`, `provision_click`, `provision_type`, `provision_close`. Without `COTLET_API_KEY` a tool call answers: "Set COTLET_API_KEY. Get a key at https://cotlet.dev/app".

## Command line

Python 3.10+, nothing else to install. From PyPI:

```bash
pip install provision-mcp        # or run it once: uvx provision-mcp connect
provision-mcp connect
```

Or straight from this repo:

```bash
export COTLET_API_KEY="your-key"
python3 provision_agent.py connect   # ready config for Claude Code, Cursor, ChatGPT
python3 provision_agent.py status    # is Provision ready in your Cotlet.dev account
python3 provision_agent.py guide     # Provision screens and sign-in link
python3 provision_agent.py read      # open Provision, read the page, close the browser
python3 provision_agent.py tools     # list Cotlet.dev tools
python3 provision_agent.py serve     # start the stdio MCP server (same as no argument)
```

## Questions from Provision users

**Does Provision have a public API or MCP server?**

The live Provision page reports no public API, MCP server or official ChatGPT or Claude connector.

**What can the Provision integration do?**

Cotlet provides 5 hosted tools for project-document questions, scope-gap detection, scope-package generation, contract-risk flags and review checklists.

**Is this an official Provision integration?**

No. Cotlet.dev is independent and is not affiliated with Provision.
